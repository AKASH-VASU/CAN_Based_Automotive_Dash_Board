# 🚗 CAN-Based Automotive Dashboard using PIC18F4580

## 📌 Overview

A microcontroller-based automotive dashboard developed using the **PIC18F4580** to monitor and display real-time vehicle parameters received through **CAN (Controller Area Network)** communication.

The system demonstrates how electronic control units (ECUs) can exchange vehicle data over CAN and how the received information can be processed and displayed on an LCD.

## ⚙️ Features

* CAN communication for receiving vehicle data
* Real-time vehicle parameter monitoring
* LCD-based parameter display
* Interrupt-based CAN data reception
* Microcontroller-based embedded implementation
* Processing and displaying received CAN messages

## 🛠️ Hardware Used

* PIC18F4580 Microcontroller
* 10 bit ADC
* CAN Transceiver / MCP2551
* 16x2 Character LCD
* CAN-enabled nodes
* Power Supply

## 💻 Software & Tools

* MPLAB X IDE
* XC8 Compiler
* Embedded C
* PIC18F4580
* CAN Protocol

## 🔄 Working

1. Vehicle parameters are generated by CAN nodes.
2. CAN messages are transmitted over the CAN bus.
3. PIC18F4580 receives the CAN frames through the CAN controller.
4. The received data is decoded according to the configured CAN message IDs.
5. The corresponding vehicle parameters are displayed on the LCD in real time.

## 📡 CAN Communication

The project uses CAN message identifiers to distinguish different vehicle parameters. The PIC18F4580 receives and processes the required CAN frames before displaying the corresponding values.
